# GRC-Incident-Review 
*Edited and Revised Aug 28, 2026*

## Project Overview: 
This repository was created to serve as a professional Governance, Risk, and Compliance Incident Review Series. Basically to analyze real-world security incidents from a policy and process perspective. Each review demonstrates how strong technical controls can be bypassed by humans' and process(s)' failures.

## Reviews
- [Review One: Darknet Diaries EP. 36, "Jeremy from Marketing"](GRC_Reviews/ReviewOne/EP36_Jeremy_from_Marketing/) — physical access control, security awareness, authenticator management, and configuration failures mapped to NIST SP 800-53 controls, with a policy remediation plan.
